react-gmail is a tiny, typed Gmail API client for front-end apps. It signs the user in with Google, calls the Gmail REST API with their token, and turns Gmail's nested MIME messages into plain objects. It works with React or any other framework, and you don't need a backend.

What it does

The library handles four steps that you would otherwise write yourself. The page loads nothing from Google until the user clicks sign in.

Loads Google sign-in

On the first signIn() it adds Google's GIS script (accounts.google.com/gsi/client) to the page. This happens once. The script is never bundled into your app.

Gets an access token

It opens Google's consent popup for the scopes you asked for. The returned token is kept in memory only, with its ~1 hour expiry tracked.

Calls the Gmail API

Methods like listMessages() are thin fetch calls to gmail.googleapis.com/…/users/me. Every error becomes a typed GmailError.

Parses messages

parseMessage() walks the MIME tree, decodes base64url bodies as UTF-8, and returns headers, text, HTML and attachments.

Set up Google Cloud

You need an OAuth client ID before the library can sign anyone in. Setup takes about 5 minutes and is free. You don't need an API key or a client secret.

Create or pick a project

Open Google Cloud Console → New project

Any project works. One project per app keeps the consent screen and quotas separate.

Enable the Gmail API

APIs & Services → Library → search "Gmail API" → Enable

If you skip this, every call fails with api_error and status 403 ("Gmail API has not been used in project …").

Configure the OAuth consent screen

APIs & Services → OAuth consent screen (called Google Auth Platform in newer consoles)

  • User type: External, unless everyone who signs in is in your Google Workspace organization.
  • App name, support email, developer email: required. Users see these in the popup.
  • Scopes: add the Gmail scopes you will request, e.g. …/auth/gmail.readonly.
  • Test users: while the app is in Testing, add every Google account that should be able to sign in (up to 100).

Create an OAuth client ID

APIs & Services → Credentials → Create credentials → OAuth client ID

Application type
Web application
Authorized JavaScript origins
Every origin your app runs on: http://localhost:5173, https://myapp.com. Enter the origin only, with no path and no trailing slash.
Authorized redirect URIs
Leave empty. The popup token flow doesn't use them.

Copy the Client ID. It looks like 1234567890-abc123.apps.googleusercontent.com

Pass the client ID to the library

A client ID is not a secret. It ships in your front-end bundle and Google ties it to your authorized origins. An env variable keeps it out of your source code:

.env.local
VITE_GOOGLE_CLIENT_ID=1234567890-abc123.apps.googleusercontent.com

Choosing scopes

The default scope is read-only. Google sorts Gmail scopes into tiers, and the tier decides who can sign in to your app once it leaves Testing:

ScopeAllowsTierTo go public
gmail.readonly (default)Read messages, threads, labels and settingsRestrictedApp verification plus an annual third-party security assessment
gmail.metadataHeaders and labels only, no bodiesRestrictedSame as above
gmail.sendSend mail onlySensitiveApp verification, no security assessment
gmail.labelsManage labels onlyNon-sensitiveBasic brand verification
Testing mode is usually enough. Internal tools, prototypes and personal dashboards can stay in Testing indefinitely, as long as you add the people who use them as test users. Test-user tokens behave the same way: they expire after ~1 hour and the user signs in again.

Usage

Create one client at module level. In React, read the sign-in state with useSyncExternalStore, so you don't need a provider or context.

import { useState, useSyncExternalStore } from "react";
import { createGmailClient, parseMessage, type ParsedMessage } from "react-gmail";

const gmail = createGmailClient({ clientId: import.meta.env.VITE_GOOGLE_CLIENT_ID });

export function Inbox() {
  const signedIn = useSyncExternalStore(gmail.onAuthChange, gmail.isSignedIn);
  const [messages, setMessages] = useState<ParsedMessage[]>([]);

  const load = async () => {
    const { items } = await gmail.listMessages({ q: "is:unread", maxResults: 10 });
    const full = await Promise.all(items.map((m) => gmail.getMessage(m.id)));
    setMessages(full.map(parseMessage));
  };

  if (!signedIn) return <button onClick={() => gmail.signIn()}>Sign in with Google</button>;

  return (
    <>
      <button onClick={load}>Load unread</button>
      <button onClick={() => gmail.signOut()}>Sign out</button>
      <ul>
        {messages.map((m) => (
          <li key={m.id}><b>{m.subject}</b> from {m.from}: {m.snippet}</li>
        ))}
      </ul>
    </>
  );
}
import { createGmailClient, parseMessage } from "react-gmail";

const gmail = createGmailClient({ clientId: "YOUR_CLIENT_ID.apps.googleusercontent.com" });

// Must run from a user action (click), because it opens Google's popup.
button.onclick = async () => {

  console.log(profile.emailAddress, messages.map(parseMessage));
};

API reference

createGmailClient({ clientId, scopes? }) returns an object with the methods below. All Gmail calls go to users/me.

MethodReturns / does
signIn()Opens the consent popup and resolves once a token arrives. Call it from a click.
signOut()Clears the token and revokes it with Google.
isSignedIn()boolean. Becomes false once the token expires (~1 hour).
onAuthChange(cb)Calls cb(signedIn) on sign-in and sign-out. Returns an unsubscribe function.
getProfile(){ emailAddress, messagesTotal, threadsTotal, historyId }
listMessages({ q?, maxResults?, labelIds?, pageToken? }){ items: { id, threadId }[], nextPageToken? }. maxResults defaults to 10.
getMessage(id, format?)Raw Message. format: "full" (default), "metadata" or "minimal".
listThreads(params?){ items: Thread[], nextPageToken? }
getThread(id)Thread with its messages
get(path, query?)Any other read endpoint, e.g. get("labels")

Helpers

parseMessage(message){ id, threadId, snippet, from?, to?, subject?, date?, text, html, attachments[] }
getHeader(message, name)Case-insensitive header lookup
decodeBase64Url(data)Gmail's base64url to a UTF-8 string
createAuth(clientId, scope)Sign-in only, plus token()
DEFAULT_SCOPEhttps://www.googleapis.com/auth/gmail.readonly

Errors

Every failure is an Error with a code, plus a status for HTTP errors.

codeWhen
not_authenticatedNot signed in, the token expired, or Google returned 401. Call signIn() again.
auth_failedThe user closed the popup or denied access.
api_errorGmail returned an error. Check status and message.
networkOffline, or Google's sign-in script was blocked.

Security

The token is a bearer credential for someone's mailbox. The library uses safe defaults, and the rest is up to your app.

The library handles

  • Keeping the token in memory only. It is never written to localStorage or cookies.
  • Sending the token only to gmail.googleapis.com.
  • Revoking the token on signOut().
  • Read-only scope by default.

Your app handles

  • Email HTML is untrusted. Never put it in innerHTML. Render it in <iframe sandbox srcdoc> (as the demo above does) or sanitize it with DOMPurify.
  • Requesting only the scopes you need.
  • If you use a CSP, allowing accounts.google.com/gsi/, oauth2.googleapis.com and gmail.googleapis.com.
